# Resumo do Projeto (Project Brief)

## Visão Geral
Aplicativo de registro de performance de treinos na academia.

## Objetivos Principais
- Registrar treinos como conjuntos de exercícios 
- Permitir registrar a execução de treinos, registrando peso, número de execuções e tempo de intervalo
- Manter um histórico de execução de treinos para cada treino
- Permitir o estabelecimento de metas de treino
- Iniciar treinos, e ir preenchendo o treino pré definido enquanto treina, com cronômetro integrado
- Configurar agentes para sugerir mudanças de treino/planos à longo prazo, para atacar todos os grupos musculares e garantir mudanças nos treinos (personal trainer)
- Configurar agentes com a ideia de planos alimentares para fazer a dualidade de bulking/cutting
