Project Brief

## Overview
Gym Workout performance app 
## Main Goals
1. *Work as a gym data assistant*
- Register full workouts, a set of exercises
- Register workout executions, with exercise order, weight, repetitions and time between executions
- Track a workout history for every full workout registered
- Establish workout goals, and track the development
- Start workout sessions, and register the executions as you go, possibly changing the order, and using a built in timer to track the time between executions
2. *Work as a gym consultant*
- Use agents, with access to your data, to get your weak points and balance your development
