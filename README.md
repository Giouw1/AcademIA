# Overview
Projeto de gestão de treinos e desenvolvimento na academia.

Facilitar registrar e acompanhar os dados de treino.

O aplicativo foi criado completamente por agentes de IA, guiados por decisões arquiteturais descritas na pasta .agents



# Como rodar localmente

Caso queira testar, baixo o repositório, e, estando no diretório, execute `npm run build`, seguido de `npm start`
