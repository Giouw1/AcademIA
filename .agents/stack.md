## Tech Stack
# Framework and code languages
-   *Frontend*: Next JS / React (Typescript)
- **SVG Manipulation:** Use standard React inline SVGs or a lightweight library like `react-svg-pan-zoom` for the muscular heatmap. The frontend must map numeric API responses to CSS color scales (e.g., using Tailwind utility classes or dynamic hex codes).
- **Asset Storage:** All static exercise images must reside locally in the `component/exercises` directory.
-   *Backend*: Next JS: RESTful API's. *Don't* do Server Actions. Validata data with *Zod*
-   *Tests*: Vitest
# Database
-   *DBMS*: SQLite
